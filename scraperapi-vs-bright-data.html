ScraperAPI vs Bright Data: Which Costs Less?

Short answer

At 100,000 requests a month, ScraperAPI is cheaper for unprotected pages: $49 on its Hobby plan against $150 on Bright Data's Web Unlocker ($1.50 per 1,000 list rate, pay as you go). Under 32,667 requests, Bright Data costs less. On bot-protected sites, Google or LinkedIn the order flips at that list rate, since 100,000 such pages need ScraperAPI's $299 Business plan. But Bright Data's docs say harder "premium domains" cost more (rate not published), so check the zone's Estimated cost before relying on the flip.

Which is cheaper for 100,000 requests a month?

It depends on the target site. ScraperAPI's docs list 1 credit for a standard page, 5 for Amazon, Walmart or eBay, 25 for Google and Bing, and 30 for LinkedIn. Its pricing FAQ says sites behind Cloudflare, Datadome or PerimeterX "add 10 credits per request when we bypass them". Bright Data's pricing page lists $1.50 per 1,000 requests, but its docs say "premium domains" that are harder to unblock are "priced at the higher rate", which is not published. Its docs also send Google, Bing and other search engines to its separate SERP API.

Does either one charge for failed requests?

Neither charges for failures, by their own statements. ScraperAPI's documentation says it only charges for successful requests, which it defines as 200 and 404 status codes; requests you cancel before 70 seconds are still charged. Bright Data says you "only pay for what's successfully delivered" on the Web Scraper API and lists "Pay only for success" on the Web Unlocker.

What is the difference between Bright Data's Web Scraper API and Web Unlocker?

The Web Unlocker is the like-for-like rival to ScraperAPI: you send a URL and get the page back, billed per request. The Web Scraper API sells parsed records from specific sites instead. Bright Data says it has 1,400+ pre-built scrapers covering sites such as Amazon, LinkedIn, Instagram, Zillow and Walmart, with output in JSON, NDJSON or CSV.

Its record pricing currently mirrors the Unlocker: a free tier of 5,000 records a month, $1.50 per 1,000 records pay as you go, and a $499 Scale plan with 384,000 records included and $1.30 per 1,000 extra. A record is a parsed item, not a page fetch, so these prices are not directly comparable with ScraperAPI's credits.

Which should you pick?

  • Unprotected pages, roughly 32,667 to 21,500,000 a month: ScraperAPI's plans cost less. Below that range, Bright Data's pay as you go costs less.
  • Mostly bot-protected sites, Google, Bing or LinkedIn: at its list rate, Bright Data's Web Unlocker is cheaper at 100,000 requests, because ScraperAPI bills these at 11 to 30 credits per request. Bright Data's docs say premium domains cost more (rate not published) and point search engines to its SERP API, so check the zone's Estimated cost first.
  • Ongoing testing at zero cost: Bright Data's free tier renews monthly. ScraperAPI's headline offer is a 7-day, 5,000-credit trial. See free tiers vs free trials and what the ScraperAPI trial buys.
  • You want parsed data, not HTML: Bright Data's pre-built scrapers.
