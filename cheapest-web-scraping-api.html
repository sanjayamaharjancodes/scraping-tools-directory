Cheap Web Scraping API: Who Charges Least per Request

Nine scraping APIs ranked by what their own pricing pages say a small project pays, with the catch in each low price.

Short answer

Among APIs that publish a fixed price per basic request, the cheap web scraping API for 100,000 requests a month is Scrapfly: its $30 Discovery plan includes 200,000 credits, and a basic request costs 1 credit, about $0.15 per 1,000. ScrapingDog's $40 Lite plan is next. Below 75,000 requests, ScrapingBee's $19 Hobby plan is the cheapest fixed plan. JavaScript rendering costs 5 to 10 times more credits at every vendor here but Firecrawl, which charges 1 credit either way.

The widget compares four of these vendors on basic requests.

Which scraping API has the cheapest paid plan?

By sticker price, Oxylabs has the cheapest paid plan at $15 a month, but its pricing page does not say how many results that plan includes. Among plans that state their included volume, ScrapingBee's $19 Hobby plan (75,000 credits) is the lowest. Apify's Starter plan is also $19, but it buys $19 of platform usage, not a set number of pages.

Is there a web scraping API with no monthly fee?

Yes. Zyte API and Bright Data's Web Scraper API both bill pay as you go with no subscription. The low end applies only to sites Zyte puts in its simplest tier, and Zyte decides the tier for each site. If all your targets landed in that tier, 100,000 responses would cost $13 a month, less than any fixed plan above. Zyte's $100 monthly commitment lowers the range to $0.10 to $0.95 per 1,000.

Bright Data charges $1.5 per 1,000 records and says you "pay only for success". A record is a structured result, not a raw page, so 100,000 records at that rate would cost $150. Its $499 Scale plan includes 384,000 records, with extra records at $1.3 per 1,000.

What does a low headline price leave out?

It leaves out credit weighting: with JavaScript rendering on, each request burns more credits, so the same plan buys far fewer pages:

Once every request needs a browser, ScrapingDog's $40 plan covers the most pages; ScrapingDog vs ScrapingBee compares the two plan by plan. Premium or residential proxies cost more again: 10 or 25 credits per request at ScrapingBee, and 25 credits for a residential request at Scrapfly.

  • Failed requests. ScrapingDog says "Failed requests never charged". ScraperAPI's docs say it only charges for successful requests (200 and 404 status codes). ScrapingBee prices credits per successful request. Firecrawl bills 403 and 404 pages. Scrapfly does not bill failed scrapes, except under its fairness policy: if 30% or more of your scrapes over 24 hours (minimum 1,000) are blocked without its Unblocker, failed scrapes are billed. The Oxylabs and Zyte pricing pages we checked do not say either way.
  • Geotargeting. ScraperAPI's Hobby and Startup plans offer US and EU geotargeting only. Global targeting starts with the $299 Business plan.
  • Overage. Scrapfly lists extra credits on Discovery at $5.00 per 10,000, far more than the plan's own rate. The widget does not model overage at any vendor.
  • Trials that disagree. ScraperAPI's pricing page advertises a 7-day trial with 5,000 API credits, while the FAQ on the same page mentions 1,000 free API credits.

Which one should a small project start with?

Start on a free option and measure your own request mix before you pay. The free plans in the table have no deadline; ScraperAPI's and Zyte's trials do (free tier comparison). Once you know your share of rendered pages, re-run the numbers: ScraperAPI's credit calculator prices rendered, premium and domain-specific requests, and ScraperAPI vs ScrapingBee compares those two plan by plan.
