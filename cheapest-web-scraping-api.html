Cheap Web Scraping API: Who Charges Least per Request

Eight scraping APIs ranked by what their own pricing pages say a small project pays, with the catch in each low price.

Short answer

Among APIs that publish a fixed price per basic request, the cheap web scraping API for 100,000 requests a month is Scrapfly: its $30 Discovery plan includes 200,000 credits, and a basic request costs 1 credit, about $0.15 per 1,000. ScrapingDog's $40 Lite plan is next. Below 75,000 requests, ScrapingBee's $19 Hobby plan is the cheapest fixed plan. JavaScript rendering costs 5 to 10 times more credits at every vendor here.

Which scraping API has the cheapest paid plan?

By sticker price, Oxylabs has the cheapest paid plan at $15 a month, but its pricing page does not say how many results that plan includes. Among plans that state their included volume, ScrapingBee's $19 Hobby plan (75,000 credits) is the lowest. Apify's Starter plan is also $19, but it buys $19 of platform usage, not a set number of pages.

Is there a web scraping API with no monthly fee?

Yes. Zyte API and Bright Data's Web Scraper API both bill pay as you go with no subscription. Zyte lists $0.13 to $1.27 per 1,000 responses. The low end applies only to sites Zyte puts in its simplest tier, and Zyte decides the tier for each site. If all your targets landed in that tier, 100,000 responses would cost $13 a month, less than any fixed plan above. You cannot know that before you test your own target sites. Zyte's $100 monthly commitment lowers the range to $0.10 to $0.95 per 1,000.

Bright Data charges $1.5 per 1,000 records and says you "pay only for success". A record is a structured result, not a raw page, so 100,000 records at that rate would cost $150. Its $499 Scale plan includes 384,000 records, with extra records at $1.3 per 1,000.

What does a low headline price leave out?

It leaves out credit weighting. Each entry price above assumes plain HTML. Turn on JavaScript rendering and every request burns more credits, so the same plan buys far fewer pages:

Once every request needs a browser, ScrapingDog's $40 plan covers the most pages. Premium or residential proxies cost more again: 10 or 25 credits per request at ScrapingBee, and 25 credits for a residential request at Scrapfly.

  • Failed requests. ScrapingDog says "Failed requests never charged". ScraperAPI's docs say it only charges for successful requests (200 and 404 status codes). ScrapingBee prices credits per successful request. Scrapfly does not bill failed scrapes, except under its fairness policy: if 30% or more of your scrapes over 24 hours (minimum 1,000) are blocked without its Unblocker, failed scrapes are billed. The Oxylabs and Zyte pricing pages we checked do not say either way.
  • Geotargeting. ScraperAPI's Hobby and Startup plans offer US and EU geotargeting only. Global targeting starts with the $299 Business plan.
  • Overage. Scrapfly lists extra credits on Discovery at $5.00 per 10,000, far more than the plan's own rate. The widget does not model overage at any vendor.
  • Trials that disagree. ScraperAPI's pricing page advertises a 7-day trial with 5,000 API credits, while the FAQ on the same page mentions 1,000 free API credits.

Which one should a small project start with?

Start on a free option and measure your own request mix before you pay. Scrapfly's free plan (1,000 credits, no card), ScrapingDog's free plan (100 credits), Bright Data's 5,000 records a month and Apify's $5 of monthly usage do not force a deadline. ScraperAPI's and Zyte's trials do. The free tier comparison covers those options in detail.

Once you know what share of your pages need rendering, re-run the numbers. If you are weighing ScraperAPI, its credit calculator prices rendered, premium and domain-specific requests. The ScraperAPI vs ScrapingBee page compares those two plan by plan.
